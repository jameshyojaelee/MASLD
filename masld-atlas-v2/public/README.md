# MASLD Gene Catalog

A human-only catalog for metabolic dysfunction-associated steatotic liver disease:
bulk RNA-seq differential expression, multi-ancestry GWAS/COLOC, single-cell and
spatial biology, molecular programs, and drug-repurposing results, explored through
an interactive gene-, genetics-, and cell-level portal.

Data is served client-side (DuckDB-WASM) from the companion dataset
[`jameshyojaelee/masld-atlas-data`](https://huggingface.co/datasets/jameshyojaelee/masld-atlas-data).
