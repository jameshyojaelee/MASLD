# MASLD Multi-Evidence Atlas

A human-only MASLD (metabolic-associated steatotic liver disease) transcriptomic
atlas: bulk RNA-seq differential expression, multi-ancestry GWAS/COLOC, single-cell
and spatial biology, molecular programs, and drug-repurposing evidence, explored
through an interactive gene-, genetics-, and cell-level portal.

Data is served client-side (DuckDB-WASM) from the companion dataset
[`jameshyojaelee/masld-atlas-data`](https://huggingface.co/datasets/jameshyojaelee/masld-atlas-data).
