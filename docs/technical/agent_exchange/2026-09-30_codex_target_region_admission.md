## Scientific decision

[Inference] A target-conditioned variant-to-accessibility-region model is a scientifically distinct alternative to the current variant-only adapter. It asks for the signed marginal accessibility association at a supplied measured region, rather than one effect per variant. It is feasible to inspect input geometry now. Independent accuracy and usefulness remain unproven; an all-tested, appropriately mapped receiving population is not yet established for broad target discrimination.

Current native scoring uses a **501-bp variant-centered** ATAC mask, even with 1-Mb sequence context. It does not integrate the actual Currin peak interval. The current short adapter does not consume peak coordinates and its exact-pair query consequently refuses arbitrary targets. Therefore a region-aware readout is a meaningful untested input change; longer sequence alone does not make the response region-specific. A new target-gene model is not established by this change: Currin's variant–peak association supplies no region–gene truth.

The source beta is normalized accessibility per additional ALT dosage, a marginal association in a donor cohort. It is not the editing effect of that single variant: linkage disequilibrium can attribute a correlated variant's contribution to this beta. Region-conditioning does not resolve that identification problem. Keep beta, SE and allele definitions identical across arms; the lead file lacks SE, while existing nominal joins supply `sqrt(varbeta)` for matching variant–peak pairs. Selection on source significance must be explicit in both training and error interpretation.

A proposed target-interval readout would integrate exactly the same REF/ALT track predictions over the **entire measured peak**, provided it is inside the model output interval. Record whole-peak availability; do not silently clip a distal or wide peak and call it the same endpoint. Sequence inputs, checkpoint, runtime/card, tracks, calibration data and variants must be identical for the direct mask comparison. Existing process-to-process variation means fresh inference is experimental until reproducibility is resolved.

## Strongest fair comparator and uncertainty

Primary comparison: train-calibrated native AlphaGenome target-peak ATAC contrast versus train-calibrated native 501-bp variant-center contrast on exactly the same sequence window and common eligible variant–peak rows. A target-conditioned adapter must additionally beat that target-peak native baseline; beating a variant-only short head cannot establish the value of a learned model. Include distance/peak-width/allele metadata plus a zero prediction and a simple scalar or ridge calibration. Calibrate using development folds 2–4; fold 1 is already inspected development, and fold 0 remains closed. A raw log2 predicted-track contrast is not automatically in beta units.

Report paired native-scale MSE/MAE, signed correlation and eligibility coverage. Cluster related targets/variants and chromosome-held comparisons; different peaks at one variant are not independent. Historical 1-Mb bins are not measured LD units. Whole-chromosome uncertainty avoids that false label, but offers few replicates, excludes refitting/selection/runtime uncertainty unless explicitly included, and does not supply independent donors or studies. A final externally validated claim needs another compatible cohort with admitted effects/alleles/peak axes and documented donor/exposure separation; Wenz's selected leads and different effect field are not automatically that cohort.
