# Distinct-function assessment: RNA-based sample composition

**Decision: do not advance a new learned composition function from the inspected catalog.** Its target would differ genuinely from RNA→chromatin prediction, but no usable independent composition truth set is established. This is a finite source-metadata decision, not a claim that such data do not exist elsewhere. No fit, scan, numerical analysis, acquisition, job, or authority amendment was performed.

## Useful target and assay limit

The one candidate assessed is a donor/sample RNA input predicting a fixed broad-lineage composition vector. It could help distinguish changing cellular mixture from within-lineage changes when interpreting the Resource's frozen117 program scores. It is not a new ridge capacity setting or another chromatin endpoint.

For a single-nucleus RNA development source, the defensible target is **the proportion of retained, author-labeled nuclei belonging to each fixed lineage**, with all retained annotated nuclei as the denominator. This is a sampled-nucleus fraction, not a whole-biopsy cell fraction. For an orthogonal imaging validation, the target would instead be **the fraction of segmented and phenotyped cells in a matched tissue region**; the population, region, segmentation exclusions, and denominator must be stated. The two targets cannot silently substitute for each other.

A nonnegative mixture of RNA lineage signatures generally weights RNA contribution. Equal mixture weight does not imply equal nucleus or tissue-cell count when lineage RNA yield or capture differs. A usable count-fraction predictor therefore needs measured fraction labels and explicit assay/source qualification, rather than relabeling RNA mixture coefficients as biological cell fractions. Neither expression-derived label transfer nor program scores computed from the same RNA provide independent fraction truth.

## Frozen-program and source-finding boundaries

The integrated program permits assay-aware donor-level tests and requires a discriminating independent observation (`ALPHAGENOME_MASLD_RESEARCH_PROGRAM.md:1357–1406,2178–2198`, T21/T22 and fixed-program multicellular tests). Current `PAPER.md:304,546`, `STATUS.md:197–198`, and the atlas registry retain the frozen117 definitions and closed integration boundary. Composition labels cannot be chosen by which program improves prediction, and memberships/weights cannot be rediscovered or optimized using a receiving outcome. An author-reported lineage population or spatial finding remains source-owned; estimating it again is not a Resource discovery. No new integration, router, or clinical classifier is proposed.

**Finite missing evidence:** an admitted independent human-liver source with authoritative donor/barcode lineage labels, exact roster/QC/annotation, and documented person independence could test the sampled-nucleus estimand. Claiming tissue-cell composition additionally requires usable matched-region orthogonal cell counts and registration. Neither artifact is established here. Without it, a new fitted function would offer internal RNA-mixture reconstruction without the independent biological measurement needed to justify its usefulness; preparation stops at this critique.
