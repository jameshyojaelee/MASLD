This directory currently describes the frozen `2026-07-15-r2` analysis package
and older July campaign ledgers. It is **not** a complete release of the
standalone Resource paper defined in `docs/PAPER.md`.

The existing manifest contains only a partial legacy substrate. The current
claim ledger does not yet include the complete 117-program registry,
observability/testability requirements, source-dependency graph, MASLD Gene Catalog,
experiment-routing rules, BG-001 decision, five-figure sources, data dictionary,
or Cas13 two-paper separation. The old consistency report proves only that its
named historical package satisfied its then-current checks.

Do not extend these TSVs in place or treat their `PASS` as submission readiness.
The final release checklist in `docs/ROADMAP.md` must:

1. select and freeze the corrected bulk substrate;
2. snapshot every included upstream release by checksum;
3. build new numbers, claims, source-dependency, figure, Gene Catalog, and portal
   manifests under a new candidate release ID;
4. verify the five-figure Resource requirements and absence of Cas13 outcomes; and
5. adopt the complete package only after explicit user approval.

The July campaign briefs are historical writing/provenance records. Their
figure, journal, target-ranking, and downstream-library statements are not
current authority.
