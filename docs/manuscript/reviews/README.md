# Manuscript reviews archived

Historical figure, novelty, and reconciliation reviews were moved to
`docs/archive/reviews/`. Current scientific decisions are summarized in
[../../PAPER.md](../../PAPER.md), [../../STATUS.md](../../STATUS.md), and
[../../ROADMAP.md](../../ROADMAP.md).

An archived review remains useful for the exact release it examined, but it
does not override a later corrected source table or synchronized release.
