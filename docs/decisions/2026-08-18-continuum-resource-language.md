# Resource language approval: molecular continuum and sliding windows

Date: 2026-08-18

Decision: the Resource manuscript may use **molecular continuum** and
**sliding windows** when describing the histology-anchored analysis adapted
from Kamzolas et al. (2026; doi:10.1038/s42255-026-01543-7).

The continuum is a complementary, cross-sectional molecular coordinate.
Recorded fibrosis stage remains the clinical severity anchor. Sliding windows
are nine prespecified, overlapping descriptive summaries and cannot select
features, define significance, move boundaries, or orient an axis.

This approval does not license pseudotime language, a temporal trajectory,
longitudinal ordering, disease progression, therapeutic windows, replacement
of the canonical disease-control DEG estimand, or redefinition of fixed NMF
axes and Hotspot programs. It is revocable by changing the corresponding entry
in `config/method_exemptions.json` to `revoked`.
