# GSE267145 sequence use: owner decision, 2026-09-15

**Status: ADOPTED by the repository owner, 2026-09-15.**

## What was contradictory

`Analysis/MASLD_Model_Benchmark/config/datasets/gse267145_znf469_human_liver.toml` carried two
statements that could not both govern:

- `blockers[0]`, dated 2026-09-06, resolves the deposited H3K27ac region labels as 1-based inclusive by
  two prespecified falsifiable tests, and permits base-resolution sequence use under declared
  `counted_interval` semantics with the recorded 1-bp residual (tier 2).
- `blockers[3]`, dated 2026-09-02, ends with "the coordinate convention blocker is untouched and still
  prohibits sequence extraction".

The prohibition is the older text. It was written four days before the convention was resolved and was
never updated.

## Decision

The later determination governs. **Base-resolution sequence extraction from GSE267145 H3K27ac regions is
permitted** under the declared `counted_interval` semantics of `blockers[0]`, with the 1-bp residual
carried explicitly in any table that uses it.

Unchanged by this decision:

- Base-resolution correspondence to the called peak stays blocked. A region label is an interval, not a
  claim about where the peak boundary is.
- `coordinate_semantics_resolved` stays false. No primary source states the convention; it was inferred.
  Every guard that requires that flag to be false is untouched.
- Global dataset admission and the coordinate-dependent lanes stay blocked. Only the activated
  coordinate-independent paired-bulk TaskSpec and this tier-2 sequence route are live.
- Raw and processed data from this source are still not rehosted.

## Why it was needed now

The AlphaGenome adaptation arm can use these 99-participant H3K27ac regions as adaptation targets. Without
this decision the arm trains on accessibility and reporter labels only.
